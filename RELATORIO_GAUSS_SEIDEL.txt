ETAPA 5 — IMPLEMENTAÇÃO DO MÉTODO DE GAUSS-SEIDEL

O método de Gauss-Seidel atualiza as tensões sequencialmente. Ao calcular a
barra i, utiliza as tensões já atualizadas nas barras anteriores da iteração
e os valores correntes nas barras ainda não atualizadas. Essa é a diferença
fundamental em relação a Gauss-Jacobi, que utiliza apenas valores da iteração
anterior para todas as atualizações.

Para uma barra PQ, a atualização segue:
V_i^(k+1) = (1/Y_ii) * [((P_i - jQ_i)/conj(V_i^k)) - soma_{j != i}(Y_ij V_j)]

Na soma, V_j representa o valor mais recente disponível. Para uma barra PV,
estima-se Q a partir do estado atual, atualiza-se o fasor e ajusta-se o módulo
para o valor especificado. A barra Slack permanece fixa.

O critério de convergência utilizado é o mesmo das etapas anteriores: o maior
módulo entre os 12 mismatches precisa ficar abaixo de 1e-6 p.u. O limite padrão
é de 10000 iterações. Estes são parâmetros computacionais adotados para o
projeto, não valores necessariamente prescritos pelo professor.

Execute:
python executar_seidel.py
python -m pytest -q

Observação: os resultados dependem dos dados do sistema e da convenção de Bsh.
Confirme a convenção no enunciado original antes de usar os números no relatório.
