ETAPA 7 — INTERFACE VISUAL COM STREAMLIT

Arquivo principal: app.py

Recursos:
- Entradas para módulos iniciais das barras PQ;
- Entradas para ângulos iniciais das barras PQ e PV;
- Seleção de tolerância, limite de iterações e métodos;
- Execução comparativa de Gauss-Jacobi, Gauss-Seidel e Newton-Raphson;
- Tabela comparativa de convergência, iterações e mismatch;
- Gráfico da evolução do mismatch;
- Tabela de tensão, ângulo, P e Q calculados por barra;
- Tratamento de erros de execução e aviso quando não há convergência.

Instalação:
python -m pip install -r requirements.txt

Execução:
python -m streamlit run app.py

Os dados elétricos ficam no módulo dados_sistema.py e não são editáveis na interface.
A convenção de Bsh deve ser confirmada com a tabela original do enunciado.
